== About

Shiperman's Friend is a simple to use yet powerful ship spotter centric vessel tracker app.
It has no fancy map view or vessel history - there are plenty of apps covering that kind of features. Instead, it focuses on the needs of a ship spotter in the field observing and photographing all the vessels out there.

=== Current Status As Of August 2026

After seeing aisstream.io data going offline a lot of times it seems now to be the case that the service now got disfunct finally and forever due to intervention of a big global player in the marine data industry buying every other company it can from the market to become the one and only super provider.

As aisstream.io was the only free of charge service for ais data (and hence the only one accessible to me as a hobbyist) and the lack of alternatives this project is now also dead.

So for the time being this is the final commit as without a running service I cannot test anything.

== Features

- Using aisstream.io as it's only data source as this the only service providing AIS livedata for free. It is mandatory to create a free account and obtain an api key (also free).
- Configurable double geo fence. Ship master data and safety messages are collected within the outer bounding box whereas position data is only collected within the inner bounding box. This inner bounding box is treated as the monitoring range of the ship spotter.
- Card view of all moving and moored vessels (separate tabs) in the monitored bounding box which shows the most important infos for a vessel.
- Vessel radar view to orientate in a dense environment which can be filtered by ship category or ship name, mmsi, imo number or callsign.
- Search tab to find and spot vessels of your interest.
- Bookmark vessels of interest for later export as CSV file.
- Mark vessels for alert when they enter the inner bounding box. This feature is using extrapolated positions to alert as early as possible. When a vessel alert is set it will also be bookmarked as alerts are only in memory and not being persisted.
- Safety message tab which display all safety relevant messages which have been sent in the outer bounding box.
- Keep track of message update frequency to determine if a moored vessel will depart soon.
- Play the anthem of the ships flag if available (237 worldwide countries supported). In part taken from https://nationalanthems.info/[National Anthems Info].
- Export and import of collected ship masterdata so you can collect data overnight on your desktop and use this data on your mobile device.
- Export and import of settings. The API key is treated as a password and is stored encrypted with a platform key.
- Export
- To avoid any costs as most ship spotters are hobbyists no commercial data source is used to obtain extra infos like TEUs, etc. Unfortunately there is no free data source for this out there.
I also do not want to scrape data out of websites as this would end in a legal mess. Instead, every vessel card has a button which sends you to the vessel page of https://www.myshiptracking.com/[myshiptracking]. As the search parameter the mmsi or imo code is used (if available). I think this is a good compromise and will lead to some extra traffic for that provider.

== Usage

=== Driving Vessels Tab

The tab shows all vessels currently under way within the warning range.

The top bar shows the coordinates of you current location. When you click on it you are being sent to googlemaps to the show the location on a map.

Below y<ou can see the amount of minutes ago of the last location update, the number of vessels in the view and the currently chosen inner radius.

The indicators on the right shows the current network status with three indicators from left tot  right:

- Connectivity status: Green cost free connection available (lan or wlan), yellow costly connection available (cellular), red (disconnected)
- aisstream.io status: Green up, red down (using bottermilkgreens inofficial https://aisuptime.buttermilkgreen.fyi/[monitor api])
- Current message status: Green (we receive ais messages), red we do not receive messages for a certain time.

The aisstream.io status up does not necessary mean that we receive actually ais messages.

Under that the vessel cards are shown which contain only the information which can be obtained from aisstream.io. I decided not to scrape other webpages for additional interesting information like tonnage, TEUs etc. Instead, you can click on the middel button on the right to open a browser with the vessels page on https://www.myshiptracking.com/[myshiptracking.com]. I have chosen this provider as it is the only one which allows to search for mmsi numbers which is mandatory for this project as aisstream only sporadically provides imo numbers for vessels.

==== Rows

===== Vessel Name

Shows the vessels name on the left (if available) and on right two indicators:

- Heading with an arrow pointing to the direction
- Movement direction (in or outbound)

===== Country

The country flag and country name

===== Buttons

From left to right:

- Show vessels page on  https://www.myshiptracking.com/[myshiptracking.com]
- Show vessel location on google maps
- Show vessel location on radar page
- Play country anthem (if available)

===== Data Fields

All fields are determined either from a vessels master data or position data AIS messages. No data is scraped from other resources than aisstream.io.

- Distance in human-readable format
- Last message ago as formatted time period and in squared braces the average duration between messages (last three messages received). Higher frequency indicates mor active vessel. Especially useful info for moored vessels as the rise the message frequency drastically shortly before departure.
- Destination (if available). I try to decode the unlo code(s) for location of depart and location of destination. When the location of the destination is known from the internal port database this turns into a link which shows the position on google maps.
- Speed in knots and km/h
- Rate of turn in degrees per minute. Negative means vessel is turning left (indicated red on the radar), positive means vessel is turning right (indicated green on the radar).
- MMSI (Maritime Mobile Service Identity)
- Callsign (if available)
- IMO Number (International Maritime Organization Number) (if available)

When you click on the rightmost icon with the radar icon the radar page is opened with the selected vessel being highlighted with a white flashing circle.

The right box shows an icon for the ships category and size and draught (if available).

=== Starred Vessels Tab

This tab shows all vessels which you have bookmarked with the starred vessel button regardless if it is in range or not. When you bookmark a vessel this is indicated by a little checkmark on the bookmark icon. The current vessel data is then written to the database. The list of bookmarked vessels can be exported from the settings page. When the vessels have been exported the database table is cleared.

=== Radar Page

The radar page shows you all vessels within the inner radius to allow you to orientate in a dense spotting environment such as a harbor.

The currently selected vessel (that one where you clicked on the radar button) is highlighted with a white flashing circle. vessels having current safety messages are highlighted with a red flashing circle. Driving vessels are depicted with an arrow showing the current heading and moored vessels are displayed as a small circle by default (when the vessel is big enough its size as reported by AIS data is shown using a rectangle).
The inner bounding box is depicted by a yellow circle when the zoom range is greater.

You can hover over vessel icons to show all vessel data in short form under the cursor or thumb.

- In the top left corner you see the currently selected vessels name and below it's speed
- In the top right corner you find buttons to jump back to the previous view, zoom in and out and to open the category selector.
- In the bottom left corner the age of the current location, the number of visible vessels and the number of active safety messages are shown (in red when unread messages exist).
- In the bottom right corner you see the current zoom range

image::docs/screenshots/Screenshot_Radar Page_7.png[]

The shown vessels can be filtered by clicking on the burger menu on the top right which shows a flyover menu with all the known categories listed with their name, the standard category color and solo and mute buttons.
Using the respective solo (S) or mute (M) buttons. You can either solo or mute categories. When you change the mode from solo to mute or vice versa all categories of the respective other mode will be cleared to avoid confusion what is muted or soloed. Use the clear button below to clear all the category selections.

These filters are combined with whatever you have entered in the top search bar.

The ship count in the top bar reflects the number of filtered vessels.

image::docs/screenshots/Screenshot_Radar Page_CategoriesFilter_4.png[]

When you hover over a vessel with the mouse (or your finger on android) the most important infos for all vessels at that location is shown.

image::docs/screenshots/Screenshot_Radar Page_Hover_1.png[]

When there is a vessel which you have set up to be alerted for when it enters the inner bounds this vessel will be highlighted by a red pulsing ring.

=== Settings Tab

The basic settings tab where you can set the outer and inner radius around the current location (when use gps location is switched on), or the entered coordinates as a fallback.
The coordinates can be entered either as double values or in DMS notation. The radius can be entered either as double (not dot or fraction needed) or with either m (meters) or km (kilometers) unit.
You can switch on and off "use gps location" during your session. The location will then be updated and used as the new centerpoint for your outer and inner bounding boxes.
To obtain an API key for aisstream.io (which is currently the one and only free of charge open data source for AIS data) you have to register on their https://aisstream.io/[website] and create an API key.
